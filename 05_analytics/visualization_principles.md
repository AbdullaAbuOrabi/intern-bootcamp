# Data Visualization Principles

## Task Overview

In this task, I learned the basics of data visualization using Python. The main focus was choosing the correct chart type, making charts clear and readable, adding titles and labels, and saving the final visuals.

The task also included creating an interactive chart using Plotly and combining multiple charts into a dashboard-style layout.

## Why Visualization Is Important

Data visualization helps turn raw data into clear insights. Instead of only looking at tables, charts make it easier to compare values, identify trends, understand relationships, and detect unusual values.

## Chart Types Used

### Bar Chart

A bar chart is used to compare categories.

In this task, I used a bar chart to compare total revenue by product category. This helped show which category generated the highest revenue.

### Line Chart

A line chart is used to show trends over time.

In this task, I used a line chart to show daily revenue over time. This helped identify changes and high revenue days.

### Scatter Plot

A scatter plot is used to show the relationship between two numeric values.

In this task, I used a scatter plot to compare quantity ordered with total price. This helped show that higher quantity usually leads to higher total price.

### Box Plot

A box plot is used to show distribution, spread, and outliers.

In this task, I used a box plot to compare total price distribution across product categories. This helped identify median values, price ranges, and outliers.

### Interactive Plotly Chart

Plotly was used to create an interactive chart. The interactive chart allows hovering, zooming, and viewing exact values.

## Visualization Design Principles

A good chart should be clear and easy to understand. It should include a meaningful title, clear axis labels, readable values, and a suitable chart type.

The chart should not be too crowded. The goal is to make the insight easy to understand, not just to display data.

## Key Insights

The bar chart showed that Books had the highest total revenue.

The line chart showed daily changes in revenue and helped identify the highest revenue day.

The scatter plot showed a positive relationship between quantity ordered and total price.

The box plot showed differences in price distribution between product categories.

## What I Learned

I learned that choosing the correct chart type is important. Different charts are used for different purposes.

Bar charts are best for comparing categories. Line charts are best for trends over time. Scatter plots are useful for relationships between numbers. Box plots are useful for understanding distribution and outliers.

I also learned how to improve charts using titles, labels, annotations, and proper layout. Finally, I learned how to save charts as image files and create an interactive chart using Plotly.
